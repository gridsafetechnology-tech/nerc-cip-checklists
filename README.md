# NERC CIP checklists and templates

Free, plain-language checklists and templates for NERC CIP programs, aimed at solar, wind and battery storage
operators and anyone starting a CIP program.

| File | What it is |
|---|---|
| [checklists/cip-003-9-low-impact.yaml](checklists/cip-003-9-low-impact.yaml) | CIP-003-9 R1-R4 and the six sections of Attachment 1 (low impact), with the evidence each one needs |
| [checklists/cip-010-4-r1-r2.yaml](checklists/cip-010-4-r1-r2.yaml) | CIP-010-4 baseline items 1.1.1-1.1.5, change authorization, 30-day update, 35-day monitoring |
| [templates/cip-002-asset-inventory-worksheet.xlsx](templates/cip-002-asset-inventory-worksheet.xlsx) | CIP-002-5.1a asset inventory and impact worksheet |
| [templates/cip-003-9-low-impact-plan-outline.docx](templates/cip-003-9-low-impact-plan-outline.docx) | CIP-003-9 low impact cyber security plan outline |
| [templates/cip-010-baseline-checklist.xlsx](templates/cip-010-baseline-checklist.xlsx) | CIP-010-4 baseline and change checklist |

The YAML files are machine-readable, so they can feed your own tracker, ticketing system or scripts.

## Important

These are paraphrases for planning, not the standards. The text published by NERC at
[nerc.com](https://www.nerc.com/pa/Stand/Pages/ReliabilityStandards.aspx) is authoritative. This is not legal advice.
